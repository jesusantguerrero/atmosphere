# Marketing Tools & Shareable Sections

**Status: Draft**
**Date: May 2, 2026**

## Free Landing Page Tools (from existing features)

1. **Meal Planner** — Simplified version on landing page. Users plan their week's meals without logging in. Engine already exists: recipes, ingredients, meal types, meal plans.

2. **Shopping List Generator** — Public share tokens already built. Demo version on landing page: pick meals → get shopping list → share via link. Immediately useful, viral via WhatsApp.

3. **Budget Calculator** — Zero-based envelope budgeting already built. Stripped-down version: enter income + categories → see allocation. No login required.

4. **Net Worth Calculator** — Net worth tracking with trends exists. Simple assets vs liabilities calculator on marketing site.

## Shareable Sections (from existing app features)

1. **Shopping Lists** — Already shareable via public tokens. Expand visibility, make sharing more prominent in UX.

2. **Meal Plans** — Weekly meal plan cards shareable with partner/family.

3. **Budget Progress** — Category spending breakdowns, envelope progress cards (like YNAB screenshots people share on Reddit).

4. **Net Worth Trends** — Charts showing progress over time, shareable milestone cards.

5. **Housing Chore Schedules** — Couples sharing household duty assignments.

## Strategic Notes

- The meal planning + shopping list angle is the strongest differentiator. No finance app competitor offers this.
- Shopping lists shared via WhatsApp = organic distribution built into weekly usage.
- Free tools serve as SEO acquisition + top-of-funnel. Shareable sections drive word-of-mouth from existing users.
- Lunch Money grows purely on word of mouth ($0 marketing). These tools could accelerate the same dynamic.
- Competitive advantage vs YNAB and Lunch Money: household OS positioning, not just budgeting.
